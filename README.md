
# RecipeWise 
## Introduction
RecipeWise is a Flask web application that allows users to searcg for recipes using TheMealDB API and save favorites recipes for later viewing. 

## Features
- Search recipes
- Save favorite recipes
- View saved recipes

## Technologies
- Python
- Flask
- TheMealDB API
- Supabase
